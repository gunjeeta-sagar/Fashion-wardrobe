# Fashion Wardrobe Studio

An interactive, photorealistic teen fashion styling and wardrobe simulation web application featuring 20 couture outfits (Western Prom Gowns, Party Wear, Casual Tops & Jeans, Office Pantsuits, and Indian Ethnic Attire), 9 pairs of shoes, 16 jewelry pieces across 5 styles, hair accessories, and a full cosmetic beauty salon.

## Features
- **Photorealistic Wardrobe**: Western prom gowns, cocktail party dresses, casual denim, tailored corporate pantsuits, Punjabi salwar suits, royal lehengas, and silk sarees.
- **Dynamic Mix-and-Match**: Multi-slot jewelry (minimal, daily wear, office-going, royal Indian, and boho festival), hair accessories, and footwear.
- **1-Click Shoe Matching**: Smart outfit-to-footwear pairing buttons.
- **Beauty Salon**: Photographic curled eyelashes, winged eyeliner, eyeshadow palette, lip-texture lipsticks, subtle cheek blush, and bindis.
- **Snapshot Studio & Lookbook**: Real-time lookbook save, rating, copy look, and instant full-resolution image download.

## Deploying on Vercel
This repository is self-contained in `index.html` with zero build step required:
1. Connect this repository (`Fashion-wardrobe`) to [Vercel](https://vercel.com).
2. Leave all build settings at default (Framework Preset: **Other**, Build Command: empty, Output Directory: empty).
3. Click **Deploy**. Your wardrobe studio will be live instantly!
